FileCrawler is built on open models, public datasets, and open-source software. This page lists where each one comes from. Every model and dataset keeps its own license and terms, which are listed on the linked page.

Models used by the scanner

The file-content scan runs one of two models in your browser. You pick which one before scanning.

  • GLiNER2.5-Decide (default). An off-the-shelf text classifier from Fastino, fastino/GLiNER2.5-Decide. The scanner loads the 345 MB q4f16 mobile ONNX build, onnx-community/GLiNER2.5-Decide-mobile-ONNX, pinned to revision 880d192.
  • Spartan v6. Our team's model, fine-tuned from fastino/gliner2.5-small-v1 (74M parameters) to separate records about a person from ordinary text that only mentions one. The browser loads the 143 MB fp16 ONNX build from JACA369/sensitivity-scanner-v6, pinned to commit c368642.

Before either model runs, a set of pattern rules written by our team checks for items such as Social Security numbers, payment-card numbers, IBANs, and API keys. Those rules use no outside data.

Spartan v6 training data

Spartan v6 was trained on 8,983 English text blocks, built up over several rounds. Part of the data was written by our team's generators: sensitive and harmless records, notes, code, configuration files, logs, and look-alikes of each. The rest comes from these public datasets on Hugging Face:

  • nvidia/Nemotron-PII: documents containing personal information.
  • gretelai/synthetic_pii_finance_multilingual: synthetic financial documents, English portion only.
  • harishnair04/mtsamples: MTSamples medical transcriptions.
  • starmpcc/Asclepius-Synthetic-Clinical-Notes: synthetic clinical notes.
  • hugsid/legal-contracts: contract text, used as harmless examples.
  • wikimedia/wikipedia (English snapshot 20231101.en): encyclopedia articles, used as harmless examples.
  • fancyzhx/ag_news: AG News articles, used as harmless examples.

Any training example sharing an 8-word phrase with a test file was removed, so the model was never trained on the text it is evaluated on.

Evaluation data

Both models were compared on 647 English test files. 403 of them were written for the project by our team. The other 244 come from public data:

  • 113 held-out items from the training sources above, which the model never saw.
  • 131 items from nine public datasets that no model was trained on:
    • ai4privacy/pii-masking-400k: text containing personal information.
    • AGBonnet/augmented-clinical-notes: clinical reports.
    • coastalcph/lex_glue (LEDGAR subset): clauses from SEC-filed contracts.
    • FiscalNote/billsum: U.S. legislation.
    • abisee/cnn_dailymail: CNN and Daily Mail news articles.
    • Yale-LILY/aeslc: Enron email.
    • code-search-net/code_search_net: source code.
    • stanfordnlp/imdb: movie reviews.
    • gfissore/arxiv-abstracts-2021: arXiv paper abstracts.

Software

  • Transformers.js 4.3.0 and ONNX Runtime Web run the scanner's models with WebGPU (Apache-2.0 and MIT).
  • PDF.js 4.10.38 extracts text from PDFs (Apache-2.0).
  • fflate 0.8.3 unpacks Office and OpenDocument files (MIT).
  • Google Identity Services and the Google Drive API handle sign-in and file access.

Parts of this site's browser code are adapted from SemIf (formerly OpenJev) by TheoLeeCJ, an independent MIT-licensed project that runs language models locally in the browser. That code keeps its original license in SEMIF_LICENSE.
